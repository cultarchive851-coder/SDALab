# Лабораторна робота №2: Обчислення значення функції erf(x)

**Дисципліна:** Структури даних та алгоритми  
**Варіант:** 9  

Постановка задачі: Обчислити значення функції $\text{erf}(x)$ для заданого $x = 0.5$ двома способами: за допомогою вкладених циклів (з прямим обчисленням степенів та факторіалів) та за допомогою динамічного програмування (з використанням рекурентних співвідношень). Порівняти кількість виконаних арифметичних операцій для різних значень $n$.

---

### Математична модель:

Функція помилок обчислюється за формулою:
$$\text{erf}(x) = \frac{2}{\sqrt{\pi}} \sum_{i=0}^{n} \frac{(-1)^i x^{2i+1}}{i! (2i + 1)}$$

* **Спосіб 1 (Вкладені цикли):** Складність $O(n^2)$. На кожній ітерації факторіал $i!$ та степінь $x^{2i+1}$ обчислюються з нуля окремими циклами. Формула кількості операцій: $T(n) = 5.5n^2 + 19.5n + 7$.
* **Спосіб 2 (Динамічне програмування):** Складність $O(n)$. Кожен наступний член послідовності обчислюється через попередній: $t_i = t_{i-1} \cdot \left(-\frac{x^2}{i}\right)$. Формула кількості операцій: $T(n) = 12n + 7$.
