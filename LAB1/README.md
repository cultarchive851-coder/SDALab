Постановка задачі
Задано дійсне число $x$. Необхідно визначити значення кусково-неперервної функції $y(x)$, якщо воно існує, або вивести повідомлення про те, що функція не визначена для заданого $x$.

### Математична модель (Варіант 9):
$$y(x) = \begin{cases}  -9x^3 + 5x^2, & \text{якщо } x \in (2, 12] \cup (22, 32) \\ -x^2 - 12, & \text{якщо } x \in (-\infty, 0] \end{cases}$$

Для $x \notin D_1 \cup D_2$ функція не визначена.
